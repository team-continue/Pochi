# MPC walking

RLと独立した、平地用の低速クロール歩行です。学習済み重みは不要です。
生成済みCADモデルをそのまま使い、自由浮遊する胴体を関節トルクだけで
支えます。接触・重力・摩擦はMuJoCoが計算します。

## 表示

```bash
cd /home/k_suzuki/fun_ws/Pochi/pochi_rl
uv run --extra mpc python scripts/play_mpc_walk.py --port 8092
```

ブラウザで `http://localhost:8092` を開いてください。他のPCからは
ホストのLANアドレスを使えます。既にポートが使用中ならviserが空きポートを
選ぶので、起動ログに出るURLを確認してください。

- 水色: MPCの予測重心軌道（16ステップ、0.8秒先まで）
- 黄色: 目標重心軌道、紫色: 実際の重心の軌跡
- オレンジ: 足先目標、緑色: 最適化した接地力
- Controlsタブ: 一時停止、リセット、再生速度
- Walking speed: 変更後にResetすると新しい速度で開始

既定は0.06 m/sで前進し、30秒ごとに初期位置に戻って繰り返します。
`--loop-duration 0` で連続歩行、`--speed -0.06` で後退できます。

## 数値評価

```bash
uv run --extra mpc python scripts/eval_mpc_walk.py \
  --duration 30 --output logs/mpc_walk/evaluation.json
uv run --extra mpc pytest tests/test_mpc_walk.py
```

評価は距離、姿勢、トルク、足先クリアランス、足以外の床接触、QPの成否を
JSONで出力します。転倒や追従誤差などの基準を満たさない場合は終了コード1です。

## 構成と適用範囲

`control/centroidal_mpc.py` は位置・姿勢・速度の12次元状態を用い、20 Hzで
有限時間の凸二次計画を解きます。接地スケジュール、片側接触、摩擦錐に内接する
摩擦ピラミッド、垂直接地力の上限を制約にします。毎回、実測状態から計画し直し、
最初の接地力だけを適用します。未来の遊脚予定も現在の力配分に影響します。
ソルバーは[OSQP](https://osqp.org/docs/interfaces/python.html)です。

`control/mpc_walk.py` はFR→RL→FL→RRの固定接地順序、速度に応じた着地点、
端点速度ゼロの遊脚軌道を生成します。支持脚にはヤコビアン転置で接地力を
関節トルクへ変換し、遊脚には足先インピーダンス制御を適用します。
MuJoCo物理と関節制御は200 Hzです。関節トルクは既存RS02のピーク17 Nmと
回転速度の包絡線に制限します。モデルXMLやRLの環境・報酬は変更しません。

このMPCが最適化するのは重心軌道と接地力です。接地順序・着地点そのものの
最適化や、段差・旋回・実機の状態推定は含みません。単一剛体と小角度近似を
使うため、まずは付属の平地と低速設定で利用してください。関節限界は物理モデル、
モータ制限はトルク適用時に扱い、QPの実行可能性は全身の実行可能性を保証しません。
実機投入前には連続定格、状態推定、接触検出など別途対応が必要です。

## 確認結果

既定設定の60秒評価では、目標3.48 mに対して3.4786 m前進、最大傾き
0.90°未満、最大関節トルク6.91 Nm未満、足以外の床接触0 N、QP失敗0回でした。
MPCと共有モデルの関連テストは19件成功（CADデータ依存の4件はスキップ）。
これは付属の平地モデルでのシミュレーション結果です。
