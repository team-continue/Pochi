# main_1 schematic review

Review date: 2026-08-23  
Scope: `main_1.kicad_sch`, `MCU.kicad_sch`, `Power.kicad_sch`  
Excluded: PCB layout/routing (requested separately)

## 結論

現状は **製造・発注前OKではありません**。KiCadネットリスト、ERC、主要部品のデータシートを照合した結果、電源経路と信号経路に複数の必須修正があります。

## P0: 製造前の必須修正

1. **U2 ICM-45686のシンボルとピン番号を作り直す**
   - 実部品は14-pin LGAです。現シンボルは12ピンしかなく、例として現回路のpin 2=3V3、pin 3=GND、pin 4=SCKですが、実部品はpin 5=VDDIO、pin 6=GND、pin 8=VDD、pin 13=AP_SCLK、pin 14=AP_SDI、pin 1=AP_SDOです。
   - VDDとVDDIOそれぞれに0.1uFを直近配置します。
   - SPI配線は PA4=NSS、PA5=SCK、PA6=MISO、PA7=MOSI の方針自体は妥当です。

2. **J11/J12の48V入力マイナスをGNDPWRへ接続する**
   - J11 pin 1はD4片端との2端子ネット、J12 pin 1はD5片端との2端子ネットで止まり、GNDPWRへ接続されていません。
   - D4/D5を入力+48VとGNDPWR間のTVSにし、XT60のマイナスをGNDPWRへ直結します。

3. **Q3 drainを+48V/U13 OUTへ接続する**
   - 現在Q3 drainは `Net-(Q3-D)` に孤立し、+48Vへ到達しません。48V1側の理想ダイオード経路が切れています。

4. **STM32と絶縁UARTのネット名を統一して接続する**
   - U5 PB10=`/MCU/TTL_TX` と U10 VIB=`/MCU/UART_TX_IN` は別ネットです。
   - U5 PB11=`/MCU/TTL_RX` と U10 VOA=`/MCU/UART_RX_IN` も別ネットです。
   - 各ネットは現在それぞれ1ピンだけで、UART回路はSTM32へ接続されていません。

5. **MCUシートとPowerシートのCANネットを意図どおり接続する**
   - `/MCU/CAN1_H` と `/Power/CAN1_H`（CAN2/CAN3も同様）は階層ローカルラベルなので別ネットです。
   - 同じCANバスにするなら、階層シートピンまたはグローバルラベルで接続します。外部RJ45ケーブルでJ10とJ19を接続する設計なら、その前提を明記します。
   - Power側CANコネクタの基準GNDはGNDPWR、ISO1044のバス側はGNDDです。同じバスならコネクタのGNDもGNDDに揃える必要があります。

6. **D7/D8/D10を正しいゲート保護部品に置換する**
   - 現状はShockley diodeシンボル、値はMOSFETの `IPT015N10NF2SATMA1`、footprintはSOD-323で、BOMとして成立しません。
   - ゲート・ソース間クランプを意図するなら、電圧を決めた実在Zener/TVSのMPN、Zenerシンボル、対応footprintへ置換します。LTC4359には内部ゲートクランプもあるため、外付け要否も再判断します。

7. **C35 10000uF/50Vを再選定する**
   - 48Vレールに50V品は定常電圧の余裕がほぼありません。SMDJ48Aの最大クランプは77.4Vなので、C35はサージ時に定格超過します。
   - 最大入力電圧、TVSクランプ、温度・寿命ディレーティングから、少なくとも63V以上、条件次第で80V級を検討します。10000uFの突入電流対策も必要です。

8. **Q1のC/E接続を修正・確認する**
   - 現ネットリストではQ1 collectorが+5VP、emitterがU11 DE/REです。PNP高側駆動を意図するなら通常はemitter=+5VP、collector=DE/RE側です。
   - S9012はメーカーでピン配列が異なるため、完全なMPNを指定してシンボルとfootprintを照合します。

9. **MotorPWRのSHDN既定状態を仕様と照合する**
   - 48V時、R21+R22=30k/R23=4.7kでQ5 gateは約6.5Vとなり、Q5がU14 SHDNをLowへ引いてMotorPWRをOFFにします。
   - 「外部入力をLowにした時だけON」が仕様なら説明を追加します。電圧監視が目的なら2N7002のVGS(th)依存では精度が出ないため、コンパレータ/スーパーバイザへ変更します。

## P1: 重要な再設計・定格確認

- **U3 HT7533-1**: シンボルとデータシート欄がMCP1703のままです。HT7533-1の保証電流に対し、170MHz STM32、ICM、3個のISO1044一次側、ADuM、SP3485を含む3.3V負荷のワーストケース電流表を作成してください。余裕がなければ高電流LDOへ変更します。
- **VREF+/VDDA**: VDDAの10nF+1uFとフェライト経路は概ね妥当ですが、VREF+は+3V3へ直結され、データシート推奨の専用100nF+1uFがありません。ADC精度を使うなら追加します。L2は「600Ω」だけでなく、フェライトビーズの周波数条件・電流定格・MPNを指定します。
- **Y1**: 値は16MHz/9pFですが、登録URLの秋月 `P-02458` は20MHz品です。16MHz品またはEpsonの完全なMPNへ修正し、実際のCLと基板寄生容量からC8/C11を再計算します。
- **C4/C12**: C4は値欄が10u/0603/25Vなのにfootprintは0402です。C12の10uF/0402もDCバイアス低下が大きいため、実MPNの容量曲線で確認し、0603/0805を検討します。
- **SMDJ48A**: VRWM=48V、VBR=53.3～58.9V、VC=77.4Vです。「48V」がバッテリ公称値なら満充電電圧が48Vを超える可能性があるため、最大連続電圧基準でTVSを再選定します。
- **CAN/RS-485終端**: R7/R8/R9とR1の120Ωは常時実装です。この基板が必ずバス終端でない限り、jumper/DNPで選択式にします。外部配線にはCAN/RS-485用TVS/ESD保護も検討します。
- **MAU102**: 5V→5V/1W/200mA、出力容量上限10uFに対しC24=1uFは範囲内です。ただし非安定化出力なので、ISO1044×3、ADuM、SP485Eの最小/最大負荷で+5VP電圧を確認します。
- **ADuM121N/SP485E**: フェイルセーフ状態、温度範囲、パッケージを含む完全な注文型番を指定します。
- **LED抵抗**: 3.3V駆動のR6=47kはLED電流が極小で、視認性が不足する可能性が高いです。48V側R14/R15=47k・0402は約1mA/約49mWなので、抵抗の定格電圧と温度ディレーティングを確認し、直列分割または大きいpackageを検討します。
- **部品参照**: `QIPT015N10NF2SATMA1` は参照番号として不正です。通常のQ番号へ直し、値を実MPNにします。

## 確認できた妥当な部分

- TPS5430のR3=10k/R4=3.24kは約4.99V設定で、D1、L1、bootstrap capacitorの接続方向は妥当です。入力・出力コンデンサの電圧定格と実MPNは別途必要です。
- ISO1044×3は一次3.3V、二次+5VP、両側100nFの構成が取れています。
- MAU102のpin 1=+5V、pin 2=GND、pin 4=GNDD、pin 6=+5VPはデータシートと一致します。
- Orin J3 pin 12からR24を介してQ6 gateを駆動し、Q6 drainでNRSTをLowへ引くオープンドレイン構成、R25=100k gate pulldown、C7=100nF reset filterは妥当です。
- BOOT0はJ3 pin 29からR26=1kを介し、R2=10k pulldown付きです。J3 pin 27ではなくpin 29を使う現在の回路で妥当です。

## ERC

KiCad 10.0.3で27件（error 9、warning 18）を検出しました。ライブラリコピー不一致の警告も含みますが、1ピンだけのUARTラベルは実際の未接続を示しています。修正後はERC error=0を目標に再実行してください。

## 推奨修正順

1. ICM-45686シンボル、48V入力GND、Q3 drain、UART/CANネットを修正
2. D7/D8/D10、Q1、MotorPWR SHDN、C35/TVSを確定
3. U3電流予算、VREF、Y1、受動部品定格とMPNを確定
4. ERCを0 errorまで再確認
5. その後にPCBレビュー（クリアランス、電流容量、熱、絶縁、リターン経路）へ進む
