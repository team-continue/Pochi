# Pochi D435 縦置きマウント v4

ボード側のインサート穴を、**印刷時から丸穴φ4.0 mm・深さ6.7 mm** に変更。
M3熱圧入インサートはユーザー指定の外径4.6 mm・長さ5.7 mmが基準。
小さい案内穴やドリル仕上げ工程はない。印刷後にバリを除去して熱圧入する。

RealSense側は承認済みv2の固定を維持する。
M3×8ねじ2本・45 mmピッチ・6 mm受け・公称挿入2 mm。
カメラ姿勢、工具通路、接触面は同じ。

## 印刷・組み立て

1. `exports/d435_portrait_down30_v4_print_mm.stl` を用意した姿勢で印刷する。
   30°版は約53 × 70 × 50 mm。25〜45°の5°刻みのSTLも同梱。
   0.4 mmノズル・0.2 mm積層・外周6本・上下6層・充填50%を初期条件とする。
   インサート穴は直径4 mmの水平丸穴なので、上部の短い橋はブリッジとして印刷する。
   スライス検証はサポートOFFの設定で行う。材料・温度は使用プリンターのプロファイルに合わせる。
2. 穴のバリを取り、ボードに接する平面からM3インサート4個を熱圧入する。
   面と同じ高さまで入れ、冷えてからねじの通りを確認する。
3. 先にRealSenseをM3×8ねじ2本で固定する。斜面裏の工具通路を使用する。
4. 正面板の中央4穴へ合わせ、**ボード裏からM3×8ねじ4本と座金4枚**で固定する。
   穴中心は横±15 mm・縦±24 mm（横30 × 縦48 mm）。
5. USBケーブルをカメラ側面へ逃がし、機体側で保持する。

板3 mm・座金0.5 mmのとき、ボードねじはインサートへ公称4.5 mm入る。
カメラねじの公称挿入は2 mmで、メーカーの最大3 mmを超えないよう確認する。

インサートの基準寸法とφ4の下穴径は
[ruthexメーカー寸法表](https://www.igo3d.com/mediafiles/Sonstiges/Ruthex/ruthex_Datenblatt_RX-Serie.pdf)
のRX-M3x5.7に基づく。周囲にメーカー最小肉厚1.6 mm以上を残す。

## ファイルとGUI

- `*_v4_print_mm.stl`: 印刷方向に配置した印刷用。下穴は最初からφ4 mm。
- `*_v4_assembly_mm.stl`: 同じ形状の取り付け座標版。
- `exports/pochi_d435_mount.zip`: v4の全STL・OpenSCAD・生成/検証Python・寸法記録・説明書。
- `archive_v3/pochi_d435_mount_v3.zip`: 小さい案内穴の旧版。配布ZIPへ含めない。

同じLANの **http://192.168.201.32:8790** で表示し、印刷STLとZIPをダウンロードする。
「取り付け状態」「パーツ単体」「印刷姿勢」はすべて同じφ4穴の形状。
「ボード接触面（インサート）」で背面を見ることができる。
「ねじを表示」をOFFにすると、インサートを隠して丸い下穴を確認できる。

```bash
pochi_rl/.venv/bin/python mechanical/d435_mount/generate.py
pochi_rl/.venv/bin/python mechanical/d435_mount/viewer.py --host 192.168.201.32 --port 8790
```

## 検証範囲

全角度で閉じた一体立体・CAD穴中心一致・φ4下穴・インサート周囲の肉厚・
ねじ入り量・カメラ外形との非干渉を検証する。
RealSense固定範囲はv2と幾何学比較し、数値丸め誤差だけであることを確認する。

PrusaSlicer 2.8.1で、サポートOFF・0.4 mmノズル・0.2 mm積層・外周6本・充填50%の
印刷経路を検証する。**v4では自動サポート判定ゼロというv3の検証を引き継がない。**
結果は `exports/manifest.json` と `exports/print_checks.json` にSTLハッシュとともに記録する。
実印刷・熱圧入・耐荷重試験は未実施。検証用G-codeはプリンター固有の設定ではなく配布しない。

カメラ寸法の根拠は
[メーカー図面 p.113](https://www.realsenseai.com/wp-content/uploads/2020/06/Intel-RealSense-D400-Series-Datasheet-June-2020.pdf#page=113)。
GUIのカメラ・インサートは模式図。
